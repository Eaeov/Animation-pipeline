## 一、发布前安全检查（最重要）

### 1.1 密钥泄漏扫描

```bash
cd D:/Desktop/AI/anime-pv-pipeline

# 扫描常见密钥格式
grep -rInE "(sk-[a-zA-Z0-9]{16,}|AKID|AccessKeySecret|appsecret|ghp_|github_pat_)" \
  --include="*.py" --include="*.yaml" --include="*.yml" --include="*.md" --include="*.sh" \
  --exclude-dir=.git . \
  && echo "❌ 发现疑似密钥!" || echo "✅ 未发现密钥"
```

- [ ] 无 DashScope API Key（`sk-` 开头）
- [ ] 无阿里云 AccessKey（`LTAI` / `AKID` 开头）
- [ ] 无微信小程序 secret
- [ ] 无数据库/Redis/MQ 明文口令
- [ ] 确认 `DASHSCOPE_API_KEY` 只从环境变量读取（查 `config.py`）

### 1.2 git 历史检查

```bash
# 注意: 这一步检查的是**历史提交**, 不只是当前文件
git log --all --oneline
git log --all -p --diff-filter=A -- "*.yaml" "*.env" | grep -iE "sk-|secret|password" || echo "✅ 历史中无密钥"
```

- [ ] 历史提交中没有密钥（如果有，**必须**用 `git filter-repo` 清洗后再推）
- [ ] 历史提交中没有大文件（视频/zip）

### 1.3 大文件检查

```bash
# 列出所有被跟踪的文件, 按大小排序
git ls-files -z | xargs -0 du -h 2>/dev/null | sort -rh | head -20
```

- [ ] `tools/ffmpeg/` 未入库（约 400MB）
- [ ] `assets/source/` 与 `assets/character/` 的实际素材未入库

## 三、发布操作

### 方式 A：用 gh CLI（推荐，需先安装）

```bash
# 安装 (任选)
winget install GitHub.cli
# 或 scoop install gh

# 登录
gh auth login

# 创建并推送
cd D:/Desktop/AI/anime-pv-pipeline
gh repo create anime-pv-pipeline --public --source=. --push \
  --description "动画 PV 人物替换 AI 管线 —— 可复用性优先的五阶段管线 + 三层评估体系"
```

### 方式 B：手动创建

1. 打开 https://github.com/new
2. Repository name: `anime-pv-pipeline`
3. **不要**勾选 "Add a README file"（否则会冲突）
4. **不要**选 .gitignore / license（本地已有）
5. 创建后：

```bash
cd D:/Desktop/AI/anime-pv-pipeline
git remote add origin https://github.com/<你的用户名>/anime-pv-pipeline.git
git branch -M main
git push -u origin main
```
